# Room Booking

사내 회의실 예약 서비스. 구성원은 빈 시간대를 조회하고 예약하며, 관리자는 회의실을 열고 닫습니다.

## 구조
- `app/store.py` — 예약 저장소 (SQLite)
- `app/booking.py` — 예약 생성·취소, 겹침 검사
- `app/slots.py` — 빈 시간대 계산 (30분 단위)

## 규칙
- 같은 회의실의 예약은 시간이 겹칠 수 없습니다. 동시 요청 충돌은 DB 제약으로 막습니다.
- 예약은 최대 4시간입니다.
- 닫힌 회의실에는 예약할 수 없고, 닫을 때 이후 예약은 자동 취소되고 예약자에게 알림이 갑니다.
