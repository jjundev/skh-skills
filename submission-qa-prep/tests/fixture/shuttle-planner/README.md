# Shuttle Planner

HR 운영자가 출근 셔틀 노선을 생성하고, 구성원이 자기 노선을 조회하는 서비스입니다.

## 구성
- `src/api.py` — HTTP 핸들러 (노선 생성 요청, 작업 상태 조회, 구성원 노선 조회)
- `src/jobs.py` — 생성 작업 큐와 상태 저장
- `src/planner.py` — 노선 계산 (기준선 + 지역 탐색)
- `src/dataset.py` — 활성 데이터셋(구성원, 차량, 이동시간) 관리

## 동작
1. 운영자가 `POST /plans`를 호출하면 작업이 생성되고 `job_id`가 반환됩니다.
2. 워커가 작업을 꺼내 활성 데이터셋 스냅샷으로 노선을 계산합니다.
3. 계산이 끝나면 계획이 저장되고, 구성원은 `GET /me/route`로 자기 노선을 봅니다.

## 운영 규칙
- 차량 정원을 넘겨 배정하지 않습니다.
- 모든 구성원은 출근 시각 이전에 도착합니다.
- 노선당 최대 탑승 시간은 60분입니다.

## 신뢰성
- 최적화는 시간 제한(기본 2초)에 걸리면 그때까지의 최선해를 반환합니다.
- 계획 생성 중 데이터셋이 바뀌면 해당 계획은 `STALE`로 표시되어 게시되지 않습니다.
- 워커 프로세스가 죽으면 작업은 자동으로 재시도됩니다.
