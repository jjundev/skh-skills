# submission-qa-prep

제출물을 근거로 시험 LLM의 확인 질문을 예상하고, **사용자가 5분 안에 복붙 없이 자기 말로 칠 수 있는** 모범 답안을 짝지어 채팅으로 낸다.

입력: 제출물 경로(기본 cwd), `--n <k>` 카테고리당 페어 수(기본 3), `--transcripts <경로>` C6용 AI 세션 기록(줄 때만 읽음).

## 절차
1. 제출물 전체를 읽는다. 시험관이 볼 문서(README, AI_COLLABORATION.md, 설계 문서)는 문장 단위로 본다. git이면 `git log --stat`.
2. 제출물의 테스트 명령을 찾아 5분 타임아웃으로 실행한다(macOS에는 `timeout`이 없으니 도구 자체 타임아웃을 쓴다). 의존성 설치는 하지 않는다. 동작을 확인하는 실험이 필요하면 제출물을 임시 디렉터리에 복사해서 그 복사본에서만 돌린다.
3. **주장 원장**을 만든다: 문서의 모든 주장 → ✅ 코드+테스트 / 🟡 코드만 / ❌ 근거 없음, 각각 `file:line`.
4. [references/question-taxonomy.md](references/question-taxonomy.md)의 C1–C6 각각에서 `--n`개 질문을 만든다. 질문은 그 문서의 "질문 모양"을 따르고 제출물의 고유명사·문서 문장을 인용한다. 카테고리 안에서는 ❌/🟡 주장과 문서에 이름이 나온 항목을 먼저 고른다.
5. 아래 페어 템플릿으로 답안을 쓴다.
6. 검증 패스: 출력에 적은 모든 `file:line`을 다시 열어 그 줄에 주장한 내용이 있는지 확인하고, 없으면 고치거나 지운다.

## 근거의 출처 두 가지
답안의 사실마다 출처가 둘 중 하나다. 확인용 근거에 태그로 붙인다.

- **[제출물]** — 저장소 안에 있는 것: 코드, 문서, 테스트, 커밋. 모범 답안은 이것만 1인칭 과거형("~했습니다", "~로 확인했습니다")으로 쓴다.
- **[이번 점검]** — 이 스킬이 지금 실행하거나 관찰한 것. 모범 답안에서는 "~하면 확인할 수 있습니다", "코드상 ~가 됩니다"처럼 현재형·조건형으로 쓰고, 맨 앞 "제출 전에 직접 돌려볼 것" 목록에 명령을 넣는다. 사용자가 직접 돌려본 뒤에야 1인칭 과거형으로 말할 수 있다.

문서에 적히지 않은 사용자의 경험(문제를 처음 알게 된 계기, 거절한 AI 제안의 구체적 내용, 당시 판단 이유)은 답안에 `[본인 기억으로 채우기: 무엇을]` 칸으로 남긴다.

## 출력 (채팅만, 이 순서)
파일을 쓰지 않는다.

1. `## 약점 Top 3` — ❌ 주장과 시험관이 파고들 결함, 각 한 줄 + `file:line`.
2. `## 제출 전에 직접 돌려볼 것` — [이번 점검] 근거를 재현하는 명령 목록.
3. `## 예상 질문` — C1→C6 순서, 페어 템플릿.
4. `## 주장 원장` — 표: 주장 | 문서 위치 | 상태 | 코드·테스트 위치.

### 페어 템플릿
```
### C<카테고리>-<번호>. <질문>
- 출제 근거: <문서 file:line "인용"> 또는 <코드 file:line>
- 모범 답안: <1인칭 경어체 250–450자. 결론 → 이유 → 근거(테스트·명령·파일 이름) → 한계·미구현 순>
- 외울 키워드: <3개, · 로 구분>
- 확인용 근거: [제출물] <file:line, 테스트 이름> / [이번 점검] <명령 → 결과>
- 꼬리 질문: <시험관이 이어서 물을 것 하나 + 한 줄 답 방향>
- ⚠ 본인 확인: <[본인 기억으로 채우기: …] 칸이 있으면 여기 모은다. 없으면 "없음">
```

## 자주 하는 실수
| 실수 | 대신 |
|---|---|
| 이번에 돌린 실험을 "직접 돌려 보니 …였습니다"로 씀 | [이번 점검] 태그 + 조건형 문장 + "직접 돌려볼 것" 목록 |
| AI 협업 과정의 빈 부분을 그럴듯하게 메움 | `[본인 기억으로 채우기]` 칸 |
| 질문을 단답형으로 만듦 ("~하면 어떻게 되나요?") | taxonomy의 복합 질문 모양 |
| 질문을 수십 개 냄 | 카테고리당 `--n`개, 우선순위대로 |
| 답안이 길어 5분 안에 못 침 | 450자 넘으면 한계 문장부터 줄이고 나머지는 꼬리 질문으로 |
